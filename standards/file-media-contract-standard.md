# File & Media Contract Standard — معيار عقود الوسائط والملفات

> يُحدد هذا المعيار القواعد العامة لإدارة الملفات والوسائط: الرفع، التخزين، المعالجة، الوصول، دورة الحياة، والحدود.
>
> يبني على `EP-MEDIA-001..006` و`EP-DATA-003`.
>
> **الملكية:** موديول الوسائط (`{{MODULE_CODE}}`) هو المالك الحصري لرفع وإدارة الوسائط (`EP-MEDIA-002`).
>
> القواعد المرتبطة بحزمة تقنية بعينها (مزوّد Object Storage وCDN) تُطبَّق عبر ملف تعريف الحزمة `profiles/<name>/`؛ الافتراضي `laravel-react`.

---

## 0. الغرض والنطاق

يُحدد: قواعد الرفع والتحقق، التخزين في Object Storage، المعالجة الخلفية (ضغط، Thumbnails)، الوصول الآمن (Signed URLs)، الحدود المعتمدة، ودورة حياة الوسائط.

---

## 1. الملكية والاستهلاك

### FMC-001 — موديول الوسائط مالك حصري

**التصنيف:** `MANDATORY`

كل عملية رفع أو معالجة أو حذف وسائط تمر عبر موديول الوسائط (`EP-MEDIA-002`). الموديولات المستهلكة ترتبط بالوسائط عبر `media_file_id` (`DD-016`).

---

## 2. حدود الوسائط

### FMC-002 — الحدود المعتمدة

**التصنيف:** `MANDATORY`

تُطبق حدود `EP-MEDIA-003`. القيم تُثبَّت لكل مشروع بقرار معتمد في `project-decisions.md` وتُقرأ من موديول الإعدادات لا تُكتب في الكود (`CS-004`):

| الحد | القيمة | المرجع |
|---|---|---|
| حجم الصورة | ≤ `{{IMAGE_MAX_SIZE_MB}}` MB | قرار المشروع |
| عدد الصور الإضافية (لكل كيان) | ≤ `{{IMAGES_MAX_PER_ENTITY}}` | قرار المشروع |
| حجم الفيديو | ≤ `{{VIDEO_MAX_SIZE_MB}}` MB | قرار المشروع |
| مدة الفيديو | ≤ `{{VIDEO_MAX_DURATION_SEC}}` ثانية | قرار المشروع |
| عدد الفيديوهات (لكل كيان) | `{{VIDEOS_MAX_PER_ENTITY}}` | قرار المشروع |
| أنواع الصور المسموحة | JPEG, PNG, WebP | `PROPOSED` |
| أنواع الفيديو المسموحة | MP4 | `PROPOSED` |

### FMC-003 — التحقق عند الرفع

**التصنيف:** `MANDATORY`

قبل قبول الملف:

1. التحقق من نوع الملف (MIME type + امتداد).
2. التحقق من الحجم.
3. التحقق من مدة الفيديو.
4. رفض الملفات غير المطابقة مع رسالة واضحة (`ECS-005`).

---

## 3. التخزين

### FMC-004 — Object Storage

**التصنيف:** `MANDATORY`

الوسائط تُخزن في Object Storage خارجي (المزوّد يُحدد في ملف تعريف الحزمة). لا تُخزن في قاعدة البيانات (`DMOD-031`).

### FMC-005 — بنية التخزين

**التصنيف:** `MANDATORY`

```text
/{environment}/{module_code}/{entity_type}/{entity_id}/{file_type}/{filename}
```

مثال: `/prod/ord/orders/123/images/front_abc.jpg`

### FMC-006 — البيانات الوصفية

**التصنيف:** `MANDATORY`

كل ملف يُسجل في كيان ملف الوسائط (`MediaFile` — الكيان العابر المملوك لموديول الوسائط) مع:

| الحقل | الوصف |
|---|---|
| `id` | معرّف الملف |
| `original_filename` | اسم الملف الأصلي |
| `mime_type` | نوع MIME |
| `size_bytes` | حجم الملف |
| `storage_path` | المسار في Object Storage |
| `entity_type` | نوع الكيان المالك |
| `entity_id` | معرّف الكيان المالك |
| `module_code` | الموديول المالك للكيان |
| `status` | حالة المعالجة (§4) |
| `uploaded_by` | من رفع الملف |

## 4. المعالجة الخلفية

### FMC-007 — حالات المعالجة

**التصنيف:** `MANDATORY`

| الحالة | الوصف |
|---|---|
| `uploading` | جارٍ الرفع |
| `processing` | جارٍ المعالجة (ضغط, Thumbnail) |
| `active` | جاهز للاستخدام |
| `hidden` | مخفي (تبعًا لحالة الكيان) |
| `retention_hold` | في فترة الاحتفاظ قبل الحذف |
| `deleted` | محذوف نهائيًا |

### FMC-008 — المعالجة المطلوبة

**التصنيف:** `MANDATORY`

| العملية | تنطبق على | ملاحظات |
|---|---|---|
| إنشاء Thumbnail | الصور | أبعاد تُحدد في التنفيذ |
| ضغط الصور | الصور | مع الحفاظ على جودة مقبولة |
| ضغط الفيديو | الفيديو | `PROPOSED` — حسب الحاجة |
| Preview للفيديو | الفيديو | `PROPOSED` |

المعالجة تتم بصورة غير متزامنة (`EP-SYNC-002`).

---

## 5. الوصول الآمن

### FMC-009 — الملفات العامة

**التصنيف:** `MANDATORY`

صور الكيانات المنشورة والإعلانات العامة يمكن الوصول إليها عبر URL عام أو CDN.

### FMC-010 — الملفات الخاصة

**التصنيف:** `MANDATORY`

الوثائق الشخصية والتقارير الحساسة يُصل إليها عبر Signed URLs بصلاحية محدودة (`EP-MEDIA-004` — المدة `{{SIGNED_URL_TTL_HOURS}}` ساعة تُثبَّت بقرار المشروع).

---

## 6. دورة الحياة

### FMC-011 — دورة الحياة

**التصنيف:** `MANDATORY`

- عند أرشفة الكيان: الوسائط تُخفى (`ACTIVE` → `HIDDEN`) — لا تُحذف.
- عند استبدال وثيقة حساسة: النسخة القديمة في `RETENTION_HOLD` لمدة `{{RETENTION_HOLD_DAYS}}` يومًا ثم حذف.
- Lifecycle السحابي التفصيلي (أرشفة، نقل بين الطبقات): `OPEN`.

### FMC-012 — حذف الحساب

**التصنيف:** `MANDATORY`

عند حذف حساب (وفق `business-rules-global.md` — سياسات الاحتفاظ والحذف):

- سجلات الكيانات الجوهرية المرتبطة بالحساب لا تُحذف — تُخفى عن العامة.
- الوسائط المرتبطة تُخفى مع السجل.
- الوثائق الشخصية تخضع لسياسة الاحتفاظ.

## 7. بوابة الجودة

### FMC-013 — قائمة التحقق

**التصنيف:** `MANDATORY`

| # | البند | المرجع |
|---|---|---|
| 1 | كل رفع يمر عبر موديول الوسائط | `FMC-001` |
| 2 | الحدود مُطبقة (حجم، عدد، مدة) | `FMC-002` |
| 3 | التحقق من النوع والحجم عند الرفع | `FMC-003` |
| 4 | لا وسائط في قاعدة البيانات | `FMC-004` |
| 5 | Signed URLs للملفات الخاصة | `FMC-010` |
| 6 | دورة الحياة مُطبقة | `FMC-011` |
