# قائمة تحقق: إغلاق موديول

للموديول ثلاثة إغلاقات متتابعة، لكل واحد بوابته البشرية. لا يُعلَن إغلاق قبل تقرير مقيس واعتماد مالك المنتج.

## أ. إغلاق Phase 0 (التحليل ومواصفات الواجهات)

- [ ] الوثائق الست مكتملة: `requirements` · `business-rules` · `user-flows` · `screen-inventory` · `permission-matrix` · `screens/SCR-*`.
- [ ] كل `FR-*` له `BR-*` أو تبرير، وكل شاشة في الجرد لها مواصفة، وكل مواصفة تُحيل إلى تدفق.
- [ ] مصفوفة التغطية: لا متطلب بلا شاشة ولا شاشة بلا متطلب.
- [ ] التحقق من الوظائف المشتركة: ما يملكه موديول آخر مُشار إليه لا مكرَّر.
- [ ] بوابات جودة التوثيق المطلوبة في المستوى المختار نُفِّذت وتقاريرها في `docs/99-quality/`.
- [ ] لا قرار مُخترَع في المحظور (المال، الصلاحيات، القانون، الخصوصية، الملكية).
- [ ] بنود `OPEN` مرفوعة لمالك المنتج ومسجَّلة بعد موافقته، وأيّها حاجب مُعلَن.
- [ ] `module-readiness-review.md` بقرار نهائي: جاهز · جاهز بشروط · غير جاهز.
- [ ] اعتماد مالك المنتج مسجَّل، وتحديث أعمدة التقدم في `module-registry.md`.

## ب. إغلاق الحزمة الهندسية

- [ ] الوثائق الخمس مكتملة: `data-model` · `api-contracts` · `user-stories` · `test-scenarios` · `traceability-matrix`.
- [ ] كل `ENT-*` يُردّ إلى `BR-*`/`FR-*`، وكل `API-*` إلى `FR-*` + `BR-*`، وكل `TS-*` إلى معيار قبول شاشة.
- [ ] لا كيان ولا حقل ولا نقطة API بلا مصدر في Phase 0 — ما نقص رُفع `OPEN` لا مُلئ بالاجتهاد.
- [ ] العقود العابرة مسجَّلة في سجل العقود المشتركة مع الموديول المالك.
- [ ] بوابات `HG-E-*` التي مرّت بها الحزمة مذكورة.
- [ ] `module-development-readiness-review.md` بحالة: `DEVELOPMENT READY` · `CONDITIONALLY READY` · `NOT READY`.
- [ ] اعتماد مالك المنتج مسجَّل.

## ج. إغلاق التنفيذ

- [ ] كل شريحة من شرائح الموديول أُغلقت بقائمة `slice-closure.md` ولها دليل في المتتبع.
- [ ] جرد مقيس: نقاط API المبنية مقابل `api-contracts.md`، الشاشات المبنية مقابل `screen-inventory.md`، الكيانات مقابل `data-model.md`. الأمر المقيس مكتوب بجانب كل رقم.
- [ ] السيناريوهات: المُنفَّذ والمُعلَّق بقرار بعدده.
- [ ] مصفوفة التتبع لا تحوي عنصرًا منفَّذًا بلا صف ولا صفًا بلا كود.
- [ ] الشاشات اجتازت المطابقة البصرية (أو إيقافها معلَن بقرار).
- [ ] لا قيمة قابلة للضبط داخل الكود؛ كل قيمة مالية غير مبذورة والغياب مقصود ومُختبَر.
- [ ] الحدود المعمارية خضراء: لا استيراد مباشر ولا مفتاح أجنبي ولا JOIN عابر.
- [ ] الديون والملاحظات المفتوحة مسجَّلة بمعرّفاتها وخطورتها ومرحَّلة صراحةً.
- [ ] تقرير إغلاق الموديول معروض، وقرار مالك المنتج مسجَّل في سجل القرارات، وحالة الموديول محدَّثة في المتتبع وسجل الموديولات.
