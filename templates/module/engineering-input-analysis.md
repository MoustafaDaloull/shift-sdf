## قواعد هذه الوثيقة

- **أول وثيقة هندسية** وأساس ما بعدها: تحليل مشتق من حزمة Phase 0 المعتمدة، لا يُنشئ متطلبًا ولا قاعدة ولا يحسم قرارًا مفتوحًا.
- تمسح **كل** ملفات Phase 0 للموديول، وتوثق صيغ المعرّفات الفعلية وانحرافاتها عن الصيغة القياسية مقارنةً بخريطة المعرّفات (`identifier-alias-map.md`).
- الكيانات (§7) ونقاط API (§8) **تقديرية** هنا — تُحسم في `data-model.md` و`api-contracts.md`.
- قواعد الأمن المستخلصة: `SEC-{{MODULE_CODE}}-NNN` — كل قاعدة تُردّ إلى `BR-*` أو قرار.
- القرارات المفتوحة والتعارضات (§12) تُصنَّف **حاجبةً أو غير حاجبة** وتُرفع لمالك المنتج (Human Decision Gate)؛ **لا تُحسم أي مسألة قانونية أو مالية أو تشغيلية تلقائيًا**.
- الافتراض المؤقت يوسم `PROPOSED` ويُبرَّر، ولا يُبنى عليه نموذج بلا وسم.
- مُدخل غير مقروء آليًا (ملف ثنائي · جدول خارجي) يُسجَّل «مراجعة يدوية مطلوبة» في صدر الوثيقة لا يُتجاهل.
- تنتهي بتوصية صريحة: **بدء** أو **إيقاف** مع تبريرها.
- تُراجَع بـ`engineering-input-quality-gate.md` قبل بدء `data-model.md`.
